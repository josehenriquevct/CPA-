# CPA Sprint 3 Dias

App de estudo pra prova CPA (Anbima, programa vigente desde 01/01/2026): diagnóstico, treino intercalado com técnica Feynman, revisão espaçada, simulado cronometrado de 50 questões e resumão dos números que mais caem.

Página única (`index.html`), sem dependências de servidor. O progresso fica salvo no navegador, com código de backup pra trocar de aparelho.
